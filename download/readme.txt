多端控制台 · 被控端 部署包 v12（2026-11-12）
============================================

安装只需 3 步：
1. 把 pc_agent_web.exe、pc_agent_guard.exe、pc_agent.ini 放到同一个文件夹
   （比如 C:\被控端\）
2. 双击 pc_agent_web.exe 运行
   - 右下角托盘会出现一个小图标
   - 同时自动打开默认网页（最大化）
3. 完事！电脑会自动注册上线，洪老师那边马上就能看到

常见问题：
- 杀毒软件报毒 → 加入信任/白名单即可（自己编的软件没有病毒）
- 想退出 → 右下角托盘图标 → 设置卡 → 退出
- 想开机自启 → 托盘设置卡里点「开机自启」
- 换网络/换地方不用改任何配置，程序会自动挑能连通的线路

本包文件：
- pc_agent_web.exe    主程序（v12，直连快控）
- pc_agent_guard.exe  看护程序（防意外退出）
- pc_agent.ini        配置（已配好公网线路，开箱即用）

注意：pc_agent_guard.exe 每隔几秒会把主程序拉起来，想彻底退出时
先在托盘设置卡里退出主程序，再删掉 guard 的计划任务（或直接删文件夹）。
