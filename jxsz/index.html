5批注是怎么写的

批注模仿李秋裕老师的二次备课样式，每课时固定 3 条，锚定在学习目标、教学难点和教学过程的关键段落上。红色小字，Word 里点开就能看。

【教学批注·重点突破】

围绕本课重点给具体教法，比如凑十法、竖式三要点、口诀记忆思路。

【教学批注·难点易错】

格式是「易错：… 突破：…」，点出二年级孩子最容易错的地方和破解办法。

【教学批注·关键节点】

提醒关键环节和数学思想，比如从实物到算式的抽象、单位换算的时机。

直接用 Word 改就行

批注内容是按教案写的初稿，等于把二次备课思路先落下来了。哪条措辞、详略想调整，直接在 Word 里右键批注修改即可，署名已经就位，不用重新生成。

6怎么用 · 常见问题

打开对应老师的文件夹在「教学设计成品汇总」里选老师A老师或老师B老师。
双击打开要用的单元文档用 Word 打开，正文带图，右侧或批注框里能看到红色批注。
按本班情况改批注、写反思直接在 Word 里改批注文字、补充教学反思，另存即可，不影响原文件。
同事拿到后要装什么软件吗？

只要能打开 .docx 即可（Word 或 WPS 都行）。批注是 Word 原生批注，WPS 也能显示和编辑。

想把这套给第三位老师用，怎么弄？

复制其中一套 12 份到新文件夹，把每份文档内部的批注署名改成新老师名字即可。这个操作交给 Agent 一句话就能完成——把这页发给他，或直接复制下面第 8 节的提示词。

文件太大、打开慢？

第三、第五单元含几十张情境图，文件 13~14 MB 属正常。不建议压缩图片，会影响清晰度。

批注看不到？

在 Word「审阅」选项卡里确认「显示批注」已开启；WPS 在「审阅 → 显示批注」。批注是红色小字，锚定在蓝色/绿色文字旁。

B. 批注的技术机制（改动必读）

Word 原生批注由三处配合：word/comments.xml 存批注正文与作者；word/document.xml 用 commentRangeStart / commentRangeEnd / commentReference 锚定到文字；rels 与 Content_Types 注册 comments 部件。批注作者就是 comments.xml 里 w:author 字段（当前值「老师A」或「老师B」）。

改署名只需替换 w:author 的值，不要重跑生成脚本——重跑会连批注文字一起覆盖，且有风险。逐 docx 用 zipfile 读写 word/comments.xml 即可，其余字节保持不动。

C. 常见任务标准做法

任务 1｜给第三位老师再做一套（只改署名）

复制任一老师的 12 份 .docx 到新文件夹 → 逐份用 zipfile 打开，仅把 word/comments.xml 中 w:author="老师A"（或老师B）替换成新名字 → 保存。用 Word COM 验证：署名唯一正确、批注数与原版一致、无损坏。

import os, shutil, zipfile
SRC = r'某某地址\教学设计成品汇总\老师A'
DST = r'某某地址\教学设计成品汇总\第三位老师'
OLD, NEW = '老师A', '老师B'  # 改成新老师名字
os.makedirs(DST, exist_ok=True)
for f in os.listdir(SRC):
    if not f.endswith('.docx') or f.startswith('~'): continue
    src, dst = os.path.join(SRC, f), os.path.join(DST, f)
    shutil.copy2(src, dst)
    tmp = dst + '.tmp'
    with zipfile.ZipFile(dst) as zin, zipfile.ZipFile(tmp, 'w', zipfile.ZIP_DEFLATED) as zout:
        for item in zin.infolist():
            data = zin.read(item.filename)
            if item.filename == 'word/comments.xml':
                data = data.decode('utf-8').replace('w:author="'+OLD+'"', 'w:author="'+NEW+'"').encode('utf-8')
            zout.writestr(item, data)
    os.replace(tmp, dst)
print('done')
任务 2｜改某条批注内容

优先让老师在 Word 里直接改（最安全）。若要批量改，编辑 教学设计_带批注\add_comments*.py 里的 COMMENTS 字典（按「单元号/标签, 课次」索引，每课 3 条），重跑脚本：第 1、2 单元用 add_comments.py 1 2，其余用 add_comments_rest.py。改完记得同步到汇总文件夹，并重做署名版。

任务 3｜从底稿重新生成带批注版

前提是 单元教学设计\ 里已有带图底稿（12 份「二年级数学第X单元教学设计.docx」等）。流程：无图干净母版 → 用 build_with_images.py / build_extra_with_images.py 把教案连同图片搬进教学过程表 → 用 add_comments.py / add_comments_rest.py 注入批注 → 输出到 教学设计_带批注\。每步都用 Word COM 校验能打开。

任务 4｜核查一套成品是否完好

用 zipfile 逐个读 word/comments.xml：统计 <w:comment 数量、提取所有 w:author 值应唯一且等于目标老师；再用 Word COM 打开确认页数、批注数、无损坏。12 份逐一核对。

D. 搬图/生成时踩过的坑（已解决，别再踩）

  • 图片撞名：跨文档复制段落时，a:blip 的 r:embed 要用目标文档的 get_or_add_image(BytesIO(blob)) 重建（按内容哈希去重），否则 Duplicate name、图串位。
  • 伪 TIFF 图：源教案里有 II 01 头的假 TIFF，Pillow 打不开；它只被 a14:imgLayer 特效引用，clone 段落时剥掉 a:extLst 即可避开。
  • Word「文件可能已损坏」根因：某些图用 mc:Choice Requires="wps" 包装，但根元素 mc:Ignorable 没含 wps。保存前给根元素 mc:Ignorable 补上 wps wpg（只补已在 nsmap 声明的前缀），Word 才能打开。
  • VML 图命名空间：qn('v:imagedata') 会 KeyError，要用完整 URI {urn:schemas-microsoft-com:vml}imagedata。
  • 模板母版自带孤儿图：干净母版要先 drop 掉全部 RT.IMAGE 关系，避免无关图残留。
