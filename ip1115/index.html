01实测复核与结论更正 重要

2026-11-14 晚，在 Ego 浏览器里打开 FOFA 结果页、点开资产卡片响应头后得到的结论。

数据是真的，但「打开就能进」这个定性是错的

FOFA 结果页原样显示 app="OpenWrt" && body="No password set" → 203 条匹配结果 / 186 条独立 IP， 卡片里的完整 IP、端口、标题、国家、组织与本地清单完全一致，采集过程没有编造。

但点开卡片的 Header 标签后，平台保存的最新响应是 HTTP/1.1 403 Forbidden + X-Luci-Login-Required: yes —— LuCI 正在要求登录，不是免密直接进后台。 对照查询 body="No password set" && header="X-Luci-Login-Required" 命中 262 条， 说明平台把不同时间 / 不同路径抓到的 body 与 header 拼在同一条资产记录里。

具体样本：87.162.5.69:80（德国 Coburg，Deutsche Telekom AG，卡片日期 2026-11-14）。 它既被「未设密码正文」查询命中，最新响应头又要求登录 —— 一条记录里就装着矛盾的双方。

因此清单名称沿用历史查询口径，应理解为「曾出现未设置密码提示的 LuCI 资产记录」， 不是可登录设备清单。同时更正两处旧判断：卡片左下角其实有逐条日期（本批 11-09 ~ 11-14，数据很新）， 以及「访问不了」的主因更可能是设备本来就要求登录，而非单纯快照过期。

06方法与边界

数据从哪来

  • FOFA 网页查询：按国家 / 端口 / 关键词拆分条件采集资产（免费账号每查询仅给第 1 页 10 条）。
  • viewdns.info：免登录在线端口扫描，17 个全球代表性 IP 逐端口实测。
  • ip-api.com：地理与运营商归属补全。
  • 被动 DNS（DoH）：Cloudflare / Google 公共解析器批量 PTR 反查。
  • Shodan InternetDB：免登录公开索引，交叉核对 IP 的 hostnames 与开放端口。
  • Ego 浏览器：实机访问平台页面、抓取页面快照与资产响应头作为取证材料。
  • 每日自动采集：定时任务重解析已知域名、查公开索引，发现新 IP / IP 漂移 / 端口变化并逐日累积，重点标注旧版 OpenWrt 与出厂免密特征。

怎么理解这些数据

  • 全部为第三方公开数据库的只读取证：未对清单中任何设备发起连接、登录或探测。
  • 测绘平台记录是快照，body / header / 域名等字段可能来自不同时间的多次抓取，不能当成实时状态。
  • 「未设置密码」是厂商出厂默认配置的公开情报，不等于某台设备当前免密可进。
  • 用途限于安全研究、资产统计、趋势分析与自家设备自查对照；请勿据此访问他人设备。
  • 本页未加入站点导航，但 GitHub Pages 属公开站点 —— 拿到链接即可访问，请勿对外传播。
