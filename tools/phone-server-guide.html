🚀 手机开机后 · 全自动启动 2026-11-12 新增

✅ 现在开机已经零操作！Magisk 开机脚本 /data/adb/service.d/kali_autostart.sh 会自动：等开机完成 → 挂载 Kali chroot → 拉起 boot_guard.sh 守护全家桶（SSH / cron / 文件终端5000 / 多端控制台5002 / Hermes飞书网关 / MQTT代理 / SakuraFrp App）。开机后约 1~2 分钟所有服务自动就位，MQTT 直接可连。

启动链路：安卓开机 → Magisk service.d → kali_autostart.sh → chroot → boot_guard.sh（每30秒轮询，谁掉拉谁）→ crontab（MQTT 代理每2分钟自愈）

备用兜底：万一开机脚本没生效，只要打开 Kali 终端（.zshrc 里有自引导），全部服务一样自动拉起。

💬 MQTT 怎么发命令

两种格式都行（qos=1）：

# 纯文本
ls /root/Desktop

# JSON（推荐，可对账）
{"id":"t1","cmd":"echo hello && date"}

回执 JSON 含 stdout / stderr / code / time / host（host=oneplus6-kali）。

  • 单条命令超时 55 秒 —— 长任务自己 nohup … & 后台化
  • 输出截断 4000 字符，要看全文用 tail 分段
  • 黑名单命令直接拒绝（rm -rf / 等）
  • 日志：/root/Desktop/phone6_mqtt_agent.log
  • 电脑端工具：D:\Desktop\服务器\手机服务器\部署MQTT代理.py（局域网一键部署）
🧪 电脑端 Python 测试片段（复制即用） 
import time, json, paho.mqtt.client as mqtt
got=[]
def on_connect(c,u,f,rc,p=None):
    c.subscribe('phone6_res_1112', qos=1); time.sleep(.5)
    c.publish('phone6_cmd_1112', 'echo MQTT-OK', qos=1)
def on_message(c,u,m): got.append(m.payload.decode())
c=mqtt.Client(client_id='t'+str(int(time.time())),
    callback_api_version=mqtt.CallbackAPIVersion.VERSION2)
c.on_connect=on_connect; c.on_message=on_message
c.connect('broker.emqx.io',1883,60); c.loop_start()
t0=time.time()
while not got and time.time()-t0<20: time.sleep(.3)
c.loop_stop(); print(got[0] if got else '无应答')

🏫 学校模式（防检测开关）2026-11-12 新增

🟢 学校网络下 MQTT / 飞书网关随便用——MQTT 是普通物联网协议（broker.emqx.io），飞书是正常 App 流量，都不算穿透。有被检测风险的只有 SakuraFrp 隧道（frp 协议有特征）。

原理：手机上有个开关文件 /root/Desktop/no_frp.flag，存在 = boot_guard 每 30 秒自动掐掉 SakuraFrp（不拉起 + 主动 force-stop）。当前状态：✅ 已开启（frp 已关，只走 MQTT）

场景操作（可通过 MQTT 远程执行）
学校/公共网络
（当前默认）		touch /root/Desktop/no_frp.flag
关 frp，只留 MQTT + 飞书
家里/安全网络
要用文件终端或 SSH 时		rm /root/Desktop/no_frp.flag
等 30 秒 boot_guard 自动拉起 SakuraFrp
