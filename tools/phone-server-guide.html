🚀 手机开机后 · 启动方式

1
解锁手机连 WiFi → 打开 Termux → 进 Kali（startkali 或你平时的进法，提示符变 root@kali）
2
整段粘贴下面命令（启动全部服务 + 文件终端 + MQTT 代理）：
bash /root/.hermes/auto-start-services.sh
cd /root/Desktop/file_terminal && nohup python3 file_terminal_server.py >> file_terminal.log 2>&1 &
nohup python3 /root/Desktop/phone6_mqtt_agent.py >> /root/Desktop/phone6_mqtt_agent.log 2>&1 &
setsid nohup /root/Desktop/boot_guard.sh >/dev/null 2>&1 &
3
验证：
ss -ltn | grep -E ':5000|:22 '        # 5000=文件终端 22=SSH
tail -3 /root/Desktop/phone6_mqtt_agent.log   # 看到「已连接 broker」即成功
💡 MQTT 代理有 crontab 每2分钟自愈，正常情况掉线会自己爬起来，不用管。boot_guard.sh 还会顺手拉起 SSH、cron 和 SakuraFrp 客户端。

💬 MQTT 怎么发命令

两种格式都行（qos=1）：

# 纯文本
ls /root/Desktop

# JSON（推荐，可对账）
{"id":"t1","cmd":"echo hello && date"}

回执 JSON 含 stdout / stderr / code / time / host（host=oneplus6-kali）。

  • 单条命令超时 55 秒 —— 长任务自己 nohup … & 后台化
  • 输出截断 4000 字符，要看全文用 tail 分段
  • 黑名单命令直接拒绝（rm -rf / 等）
  • 日志：/root/Desktop/phone6_mqtt_agent.log
  • 电脑端工具：D:\Desktop\服务器\手机服务器\部署MQTT代理.py（局域网一键部署）
🧪 电脑端 Python 测试片段（复制即用） 
import time, json, paho.mqtt.client as mqtt
got=[]
def on_connect(c,u,f,rc,p=None):
    c.subscribe('phone6_res_1112', qos=1); time.sleep(.5)
    c.publish('phone6_cmd_1112', 'echo MQTT-OK', qos=1)
def on_message(c,u,m): got.append(m.payload.decode())
c=mqtt.Client(client_id='t'+str(int(time.time())),
    callback_api_version=mqtt.CallbackAPIVersion.VERSION2)
c.on_connect=on_connect; c.on_message=on_message
c.connect('broker.emqx.io',1883,60); c.loop_start()
t0=time.time()
while not got and time.time()-t0<20: time.sleep(.3)
c.loop_stop(); print(got[0] if got else '无应答')

🩹 故障排查速查

症状原因 / 解法
MQTT 无应答tail /root/Desktop/phone6_mqtt_agent.log；代理没跑就重启它；crontab 会自动拉起
curl 报 Could not resolve host外面 WiFi 常封 DNS 53 端口。hosts 里已写死 broker IP；下别的域名可 echo 'nameserver 223.5.5.5' > /etc/resolv.conf 后试，不行就用电脑 SFTP 直传文件
frp 端口「连接被拒绝」SakuraFrp App 没连上或对应隧道没开；boot_guard.sh 会用 am 拉起 App；SSH 隧道=28636911，文件终端=28637128
隧道通但 SSH 读不到横幅手机里 sshd 没跑：service ssh start（先 ssh-keygen -A 若缺 hostkey）
文件终端 40476 打不开本机 5000 没监听 → 启动 file_terminal_server.py；或 App 里隧道 28637128 未开
代理连不上 brokeremqx 换 IP 了：电脑解析新 IP 后改手机 /etc/hosts（备份在 /etc/hosts.bak）
