它是干什么的

双击运行后全自动：检测蓝牙适配器 → 找到已配对的蓝牙麦克风（如 M1_K）→ 没连上自动触发连接 → 从电脑音响实时扩音。等于一个软件版小蜜蜂。

✅ 没有内置蓝牙的电脑也能用：插上 USB 蓝牙适配器、在 Windows 设置里配对一次麦克风，本程序就能自动连接并扩音（关键就是自动补上「连接」这一环，否则配对了麦克风端点也出不来）。

两个版本怎么选

版本特点下载
窗口版（52KB）有界面：音响下拉框、蓝牙设备列表（双击连接）、音量/延迟滑条、电平条，最直观下载
黑窗口版（43KB）无界面：双击后窗口里自动跑完连接和扩音，键盘 M 静音 / +− 调音量 / Q 退出下载

使用只需 2 步

  1. 第一次在新电脑上：先在 Windows 设置 → 蓝牙里把麦克风配对一次（系统要求，绕不过）
  2. 双击 exe → 自动连接蓝牙麦克风 → 对着麦克风说话，音响出声
⚠️ 防啸叫三件事：音箱音量压在 40% 以内、麦克风离音箱 2 米以上、别把音响选成蓝牙耳机本身。

配置文件（可选）

把 蓝牙扩音C.txt 和 exe 放同一目录，可改蓝牙设备名、音响、增益、延迟：

  • bt = M1_K 蓝牙设备名片段（模糊匹配，换了设备就改成新名字）
  • out = 音响名片段，空 = 系统默认扬声器
  • gain = 4 增益 dB，声音小就往上加｜latency = 100 延迟 ms
出问题时黑窗口版可用命令 BtAmpC.exe --list-bt 一眼看到蓝牙适配器和所有设备的状态。
