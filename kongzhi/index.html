🖥️ 多端控制台 · 连接与使用

一句话：在一台电脑上运行一个小程序，手机或其他电脑打开网页就能远程控制它 —— 发命令、管文件、看屏幕、开网页，全自动连线，不需要公网 IP、不需要服务器、不在同一个网也行。
🚀 打开在线控制台 ⬇️ 被控端下载页
1

在被控电脑上安装（只需一次）

  1. 去 下载页 下载部署包（或手机下载后传过去）
  2. 解压后 双击 pc_agent_web.exe
  3. 完成！右下角出现托盘图标，自动上线（自动开机自启，重启电脑也不用管）
💡 杀毒软件报毒点「信任」即可。程序带看护进程，意外退出 2 秒内自动拉起。
2

打开控制台，连接

  • 手机 / 平板 / 任意电脑，浏览器打开 在线控制台：
    https://hlh66.github.io/kongzhi/console.html
  • Token 已经预填好（和被控端出厂配置一致），点「连接」即可
  • 看到「已连接 broker」就绪，直接敲命令回车
✔ 无需注册、无需登录、无需在同一个局域网 —— 控制台和被控端通过公共 MQTT 服务器自动会合。
3

开始使用：常用操作速查

想做的事在控制台输入
看机器在不在线点「PING 探活」按钮（3 秒内回 PONG = 在线）
看主机名 / 内存占用__status__
截一张全屏图__screenshot__
看 IP 地址点「本机 IP」按钮（或 ipconfig）
列目录 / 管文件dir D:\ 等 CMD 命令
打开一个网页填网址点「让电脑打开这个网页」按钮
打开程序!calc（计算器）、!notepad（记事本）—— 开程序必须加 !
关机 / 重启shutdown /s /t 60（60 秒后关，shutdown /a 取消）
远程升级到最新版点「检查并自动升级」按钮
锁屏点「锁屏」按钮
⚠️ 注意：同一个 Token 的所有在线电脑都会执行收到的命令（广播）。只想控制一台时，先确认其他机器已退出。

⚡ 它是怎么连上的（原理 30 秒）

你的浏览器 ──WebSocket──▶ 公共 MQTT 服务器（broker.emqx.io） │ 被控电脑上的小程序 ◀──────┘ pc_agent_web.exe（主动订阅命令，秒级到达）
  • 被控端主动连接外网服务器，所以不管它在家、学校还是热点，都连得上
  • 实测：从点「发送」到对方电脑执行完，约 1.6 秒
  • 程序自带看护 + 自动重连 + 多线路自动切换，网络抖动自动恢复
  • 安全：命令主题带 32 位随机 Token，下发和回执双重校验，拿到 Token 的人才能控制，不要外传

❓ 常见问题

点连接失败？检查手机/电脑能不能上网；公司/校园网若封 WebSocket，换 4G/5G 试试。
命令发了没反应？被控电脑没开机或 exe 没运行。让它在被控电脑上双击 pc_agent_web.exe。
杀毒报毒？远程控制程序容易被误报，加入信任/白名单即可。
被控电脑重装系统/换机？重新下载部署包装一次就行，配置都在包里。
想改连接口令？改被控端 pc_agent.ini 里 [mqtt] token=，控制台里填同一个新值。
360 提示拦截？在 360 主页防护/浏览器保护里放行，否则它可能锁住默认浏览器设置。
