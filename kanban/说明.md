## 二、手机端怎么用（老师视角，3 步）

1. 手机浏览器打开 `http://192.168.123.51:5000/kanban/teacher`，建议「添加到主屏幕」，图标点开就像个 App。
2. 进「设置 → 批量导入名单」，把花名册整列粘进去（一行一个，支持 `1 张三`），保存。
3. 「设置 → 学生专属入口」里把每个孩子的链接发给对应家长（可复制全部 / 导出 CSV），家长打开就是自家孩子。
4. 回到「今日」，上课点「✓ 全部到齐」，再单独点几个迟到/请假的 —— 一次点名 5 秒。
5. 「提醒 → 班级公告」发一条置顶公告，学生端和家长端立刻能看到（家长回家也看得到）。

| 页签 | 能干什么 |
|---|---|
| **今日** | 出勤四色统计、实到率、快捷喊话、课堂计时器、今日记录流水 |
| **点名** | 随机点名（抽过的不会重复，直到抽完一轮）、四位一体考勤（到/迟/假/缺） |
| **积分** | 光荣榜、按理由加分（发言/作业/纪律/助人/进步/卫生）、逐个加减 |
| **作业** | **布置作业**（字段照搬《作业布置方案》）、一键复制发群、编辑/删除；家长端学生端自动显示 |
| **提醒** | 连教室电脑、定时任务（每天/每周几点，发通知或开网页）、四个一键场景 |
| **设置** | 班级名、名单导入/CSV 导出、学生专属链接、数据源、JSON 备份、清零 |

**作业栏目（2026-10-18 新增，接的是 `D:\Desktop\作业布置` 那套格式）**

- 字段：日期（可提前）、科目、⭐重点/序号、简要一句话、作业内容（一行一项）、完成要求、
  📖学习指导、📚学的是什么、🖨️可以打印、资料链接、🌟提升版、⏱时长、💡提示
- 「📋 复制发群」生成群消息文本；也可对单条复制
- **家长端**：显示最新一天的作业（全部铺开不折叠）+「○ 标记已完成」（打勾存在家长自己手机里）+「🗂️ 往期作业」折叠
- **学生端**：只显示最新一天，大字要点，投影上看得清

**发音规则**：所有改动先落本机，再异步推服务器；网络断了照常用，恢复后自动补推。
服务端有乐观锁：一台刚打开的空白页**不可能**把整份名单覆盖掉（会提示「已采用服务器的最新数据」）。

## 四、和「多端控制台」怎么联动

### 4.1 已经在手机上另起了一套控制台（2026-10-18 新建）

原来那套跑在家里的 PHP 机上，远端地址 `https://s0.v100.vip:10989/dk/` **实测已连不上**（TCP 直接拒连）。
手机上本来就有 PHP 8.4，所以直接把服务端搬过来了：

| 项 | 值 |
|---|---|
| 地址 | `http://192.168.123.51:5002/pc_agent_server.php` |
| 网页 | `http://192.168.123.51:5002/pc_agent_server.php`（同一入口，PHP 自带 UI） |
| 部署位置 | `/root/Desktop/console/`（数据在同目录 `pc_agent_data/`） |
| 启动方式 | `PHP_CLI_SERVER_WORKERS=8 php -S 0.0.0.0:5002`（8 个 worker，否则长轮询会把整站堵死） |
| 守护 | 已写进 boot_guard，实测杀掉后 40 秒内自动回来 |

**让教室电脑连到这套新控制台**（在那台电脑上改启动参数）：

```bat
pc_agent_web.exe --server http://192.168.123.51:5002/pc_agent_server.php --name 教室电脑
```

> ⚠️ 这条只在**同一局域网**可用。教室电脑如果不在家里这个网段，需要给 5002 加一条 SakuraFrp 隧道；
> 或者干脆等家里那台 PHP 机修好，继续用 10989。两套可以并存，数据各管各的。

### 4.2 看班 → 控制台 的链路

```
手机看班 ──HTTP──▶ 控制台中转 ──长轮询──▶ 教室电脑 exe
   │              (api=send)              执行 !网址 / 截屏 / cmd
   └── 通知走看班服务端广播，不占电脑通道
```

| 看班里的按钮 | 实际下发的指令 |
|---|---|
| 🖥 大屏 | `!http://…/screen`（教室电脑浏览器打开大屏） |
| 📸 截屏 | `__screenshot__` |
| 定时任务·开网页 | `!<你填的网址>` |

⚠️ **实测发现（2026-10-18 20:55）**：老地址 `https://s0.v100.vip:10989/dk/` 连不上
（TCP 拒连，不是看班的问题）。原因大概率是家里那台跑 PHP 的机器/穿透隧道没开。
看班对此做了降级：连不上就显示「无在线机器」，其余功能照常，不会卡住。
**要修**：开那台 PHP 机、确认 SakuraFrp 隧道在线；地址可在「设置 → 多端控制台地址」里改。

### 4.3 改完 boot_guard 必须重启它（踩过的坑）

bash 是边读边执行脚本的，**改一个正在运行的 .sh，正在跑的那个实例会从错位的位置继续读**，
表现就是：新加的服务怎么都不生效、日志一行不写。这次就踩到了 —— 加完条目后
`boot_guard.log` 停在昨天，杀掉 php 也没人拉。处理后：

```bash
pkill -f "[b]oot_guard.sh"
setsid nohup /root/Desktop/boot_guard.sh >/dev/null 2>&1 &
```

以后凡是改 boot_guard.sh，改完都要走这两行。

## 五、和科创项目（具身智能 · 教室电脑小管家）的关系

这个「看班」不是新项目，**是你那个参赛作品的软件内核提前落地了**：

| 申报里的功能 | 看班里的对应 |
|---|---|
| ① 课前/拖堂提醒 | 定时任务 + 大屏通知（已实现） |
| ② 远程管控教室电脑 | 多端控制台通道（已打通，等隧道恢复） |
| ③ 控制教室设备 | 预留（接智能插座/红外要加 MQTT，未做） |
| ④ 到课考勤 | 手动点名（已实现）；摄像头自动识别 → 见下 |
| 智能体层 | v1 未接大模型；路线见下 |

### 具身智能那部分，实话实说

**能实现的（软件层，成本 0）**
- 手机当「大脑」跑服务 → ✅ 已经跑起来了（这就是看班）。
- 手机浏览器调摄像头做「到课检测」→ 技术上可行（`getUserMedia` + 人脸检测），但**只能前台运行**，切后台就被系统杀，做演示可以，日常不靠谱。
- 语音播报 → 浏览器 `speechSynthesis` 能出声，手机/一体机都行。
- 自然语言操控 → 接大模型 API，把「把明天的作业发到大屏」解析成任务 JSON。**这条最值得做，也最像 Agent**。

**实现不了的（别写进申报，评委会问）**
- 手机自己走路、抓东西 —— 手机没有执行器，那是机器人本体的事。
- 「手机机器人」这个词容易被理解成实体机器人。**建议统一表述为「具身智能体（Embodied Agent）」**：
  手机是感知与决策的身体，教室电脑是执行的身体，两者靠 Agent 串起来。

**要补硬件才成立的**
| 想做的事 | 需要 | 难度 |
|---|---|---|
| 控制灯/风扇/投影 | 智能插座（米家/涂鸦）或 ESP32 + 红外 | 低，1 天 |
| 自动考勤 | 固定支架 + 常亮屏 + 前台网页 | 中，不稳定 |
| 移动/机械动作 | 底盘 + 舵机 + ESP32 | 高，不建议赶比赛 |

**结论**：以「二手手机 + 教室电脑 + Agent 软件」的形态，**软件部分今天已经能跑**，申报材料可以直接拿它当实物演示；
硬件部分只做「智能插座/红外」这一层就够了，别碰机械结构。

现在的 `pc_agent_web.exe` 是黑框常驻、靠网页操作，看不到状态。三条升级路线，从轻到重：

| 方案 | 做法 | 工作量 | 适合 |
|---|---|---|---|
| **A. 托盘 + 状态气泡** | exe 加托盘图标，鼠标悬停显示「在线 / 待执行 N / 延迟 xx ms」，右键菜单「打开控制台 / 重连 / 退出」 | 小 | 马上能用 |

建议先做 **A**（半天）：解决「不知道它到底在不在跑」这个最大的痛点；界面还是现成的网页，不重画。

### 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 手机上打不开 | IP 变了（DHCP）。跑 `python 部署.py` 会自动扫；或看路由器后台 |
| 三端有一个 404 | `file_terminal.log` 里找「看班三端未挂载」；重跑 `部署.py` 会幂等补挂 |
| 页面能开但改完没同步 | 「设置 → 数据源」被设成「只用本机」了；切回自动 |
| 学生端不弹通知 | 学生端页面要开着；教师端发送后 3 秒内出现 |
| 家长端空白 | 首次要选孩子；换设备重新选一下即可 |
| 教室电脑那边没反应 | 多端控制台（5002）挂了或被控端没开（见第四节） |
| 换手机/清理浏览器 | 数据在手机服务器上，重新打开页面自动拉回来 |
